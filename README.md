# HopeCare - Sistem Pet House Care

**HopeCare** adalah aplikasi sistem *pet house care* berbasis desktop C# dan MySQL yang dikembangkan oleh tim beranggotakan 4 orang untuk tugas akhir Praktikum Pemrograman Berbasis Objek (PBO).

---

##  Tim & Peran Saya

Proyek ini dikembangkan bersama 3 rekan tim lainnya. 

###  Peran & Kontribusi Saya (`aisyahnrul`):
* **Admin Dashboard:** Merancang antarmuka (UI) dan mengimplementasikan logika kontrol pada Dashboard Admin.
* **Feature Integration:** Mengintegrasikan seluruh modul dan fitur yang dikembangkan oleh anggota tim menjadi satu aplikasi C# utuh yang saling terhubung.
* **Database & Navigation Flow:** Memastikan koneksi MySQL dan alur navigasi antar-halaman berjalan lancar di seluruh sistem.

##  Teknologi yang Digunakan

* **Bahasa Pemrograman:** C#
* **Database:** MySQL
* **IDE / Solution File:** Visual Studio (`hopecare.slnx`)

---

##  Fitur Utama

* **Dashboard Admin:** Pusat kontrol operasional, pemantauan statistik, dan manajemen sistem.
* **Manajemen Perawatan:** Pengelolaan paket layanan *pet care*.
* **Pendataan Pelanggan & Hewan:** Modul pencatatan data pemilik dan hewan peliharaan.
* **Transaksi & Laporan:** Pencatatan riwayat layanan dan kalkulasi pembayaran.

##  Cara Menjalankan Proyek

1. **Clone Repository**[cite: 1]
   ```bash
   git clone [https://github.com/aisyahnrul/hopecare.git](https://github.com/aisyahnrul/hopecare.git)
   ```[cite: 1]
2. Pastikan server **MySQL** aktif dan impor database proyek[cite: 1].
3. Buka berkas `hopecare.slnx` di Visual Studio, lalu tekan **F5** / **Start**[cite: 1].
